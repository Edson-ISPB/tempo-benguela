# Tempo em Benguela

Página web simples que mostra a temperatura atual em Benguela, Angola.

## O que faz
- Pede os dados à API pública Open-Meteo com `fetch`.
- Lê a resposta em JSON e mostra a temperatura na página.
- Trata erros: se a API falhar, mostra uma mensagem ao utilizador.
- Botão "Atualizar" para pedir os dados outra vez.

## Tecnologias
HTML, JavaScript, API REST (Open-Meteo)

## Como usar
Abra o ficheiro `index.html` no navegador.

## O que aprendi
Como consumir uma API REST: fazer o pedido, ler JSON e tratar erros.
